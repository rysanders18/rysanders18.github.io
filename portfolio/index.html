Projects

Disco Zoo reinforcement learning

A Deep Q-Network agent that learns Disco Zoo’s rescue puzzle: find hidden animals on a 5×5 grid before the moves run out. The interesting half is an exact constraint-satisfaction probability engine that enumerates every placement consistent with the revealed tiles and feeds the resulting per-animal heatmaps into the network as a (5, 5, 14) state tensor. The agent is a convolutional DQN (~507k parameters) trained with a four-phase curriculum in a custom Gymnasium environment, with unit tests over both the environment and the probability engine. The heatmap policy alone already lifts completion rate from 9% (random) to 58%.

Python, PyTorch, Gymnasium, NumPy, pytest

RYmaphub

A browser tool that turns any image into dithered Minecraft map art and hands you the chat messages that rebuild it in game. It quantizes colors by nearest-neighbor search in CIELAB space, dithers with Floyd–Steinberg error diffusion, then encodes the result into a custom chat-message wire protocol I designed (currently v6), decoded in game by a script I wrote for the Minr server. A round-trip test suite keeps the browser encoder and the in-game decoder honest with each other. Runs live on this site, with source on GitHub.

JavaScript, canvas, color science, protocol design

Principia Biscotica

A paper deriving the optimal upgrade order for a cookie-clicker minigame, with considerably more mathematics than the problem required. It casts the game as a purchase-scheduling problem, writes down the Hamilton–Jacobi–Bellman inequality for the completion-time functional, and arrives at an index policy whose 331-purchase trajectory finishes in 1,365 seconds — where a width-600 beam search stalls in a local optimum at 7,585. Read it here.

Dynamic programming, optimization, mathematical writing
