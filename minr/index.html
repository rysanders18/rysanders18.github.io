Minr

published September 08, 2026

Systems and engines for Minr, the Minecraft challenge server, written in MSC — a small event-driven language with no bitwise operators, no break, lists capped at 1000 elements, and one shared server tick budget. Most of the fun is building real systems inside those limits.

  • RYmaphub: a map-art importer that moves 128×128 images through the chat box — symbols indexed into a 2,980-character CJK alphabet, run-length coding, per-message checksums. The browser encoder runs here; the decoder runs in game. (writeup not done yet)
  • rychess: a chess engine — negamax alpha-beta with quiescence — plus a physical board of block-display entities. The opponent walks to the board and moves the pieces. Moves are packed into a single Int by multiply and modulo, because there are no bit operators. (writeup not done yet)
  • slimeMaze: a procedural generator for a seamless slime-bounce maze of roughly 815,000 blocks, where every dead end is a translated copy of a live corridor and a relative teleport means you never notice the end. (writeup not done yet)
  • mannequin: a reimplementation of Minecraft player movement — sprint acceleration, drag, swept AABB collision — so an armour stand can sprint, jump, and coast like a player. (writeup not done yet)
  • nfa: build a nondeterministic finite automaton out of blocks, draw its transitions as particle splines, and run strings through it, with a graded bank of over 100 exercises. (writeup not done yet)
  • entity_ai: a repaired build of a broken armour-stand animation library — root-caused a silent break on 1.21.6+ and shipped a minimal patch. (writeup not done yet)
  • Harha: production scripts for the Harha map — stages, checkpoints, cosmetics, leaderboards, note-block music. (writeup not done yet)
  • An MSC language reference, maintained because there is no official one. (not published yet)
