RYmaphub

Upload an image and get a 128x128 Minecraft map, delivered as a series of chat messages you paste in game at the RYmaphub map hub. Everything below updates live as you move the controls.

Staircasing builds the map in 3D so every block gets three shades, tripling the palette. Valley mode keeps the build as low as possible. Transparent pixels stay clear on the map.

Longer messages mean fewer of them to paste. Minecraft's chat box holds 256 characters, and messages have been measured arriving at Minr at their full length, so 250 is the sensible choice; the shorter settings are only there for testing.

    How to use it

    1. Choose an image above and adjust it until the preview looks right.
    2. In game, use /warp tp rymaphub and click the import sign. The script asks for message 1.
    3. Click Copy message 1, paste it into chat, and press Enter. The button advances to the next message each time you click it.
    4. Keep going until the last message. The script checks every message as it arrives and tells you if one was mangled, so just paste that one again. Type cancel to abort.
    5. Once every message is in, the map builds and lands in your hand.
