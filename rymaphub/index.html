RYmaphub

Upload an image and get a 128x128 Minecraft map, delivered as a series of chat messages you paste in game at the RYmaphub map hub. Everything below updates live as you move the controls.

Staircasing builds the map in 3D so every block gets three shades, tripling the palette. Valley mode keeps the build as low as possible. Transparent pixels stay clear on the map. Max height caps how tall a column may get: raising it buys a little accuracy on steep gradients, but the hub needs that many blocks of clear air above its floor.

    How to use it

    1. Choose an image above and adjust it until the preview looks right.
    2. In game, use /warp tp rymaphub and click the import sign. The script asks for message 1.
    3. Click Copy message 1, paste it into chat, and press Enter. The button advances to the next message each time you click it. You never have to come back to it, though: with the page open in another window, ' or Ctrl+C copies the next one, so the whole run is alt-tab, paste, alt-tab, key.
    4. Keep going until the last message. Each one that lands plays a note a little higher than the last, so you can hear the run finish. If a message arrives mangled the script says so and waits for you to paste it again. Type cancel to stop.
    5. Once every message is in, the map builds and lands in your hand.
