RYmaphub

Upload an image and get a 128x128 Minecraft map, delivered as a series of chat messages you paste in game at the RYmaphub map hub.

For best results use a 128x128 image. Other sizes are stretched to fit. Transparent pixels stay clear on the map.

    How to use it

    1. Convert your image above.
    2. In game, use /warp tp rymaphub and click the import sign. The script asks for message 1.
    3. Click Copy message 1, paste it into chat, and press Enter. The button advances to the next message each time you click it.
    4. Keep going until the last message. The script checks every message as it arrives and tells you if one was mangled, so just paste that one again. Type cancel to abort.
    5. Once every message is in, the map builds and lands in your hand.

    If the server refuses the compact messages, switch the encoding to ASCII and convert again. It needs about twice as many messages but uses only plain characters.
