Games

published September 08, 2026

Games I’ve built, mostly running on Minr in MSC, the server’s scripting language. Writeups for each are on the way.

  • Cookie: an idle/clicker game with golden cookies, a milk multiplier, and seven upgrade ladders, running as a Minr secret. (writeup not done yet)
  • uch: a multi-round party game in the style of Ultimate Chicken Horse — run, score, draft blocks, build, repeat — built around a round state machine that owns its own timers. (writeup not done yet)
  • j100: a 100-jump parkour hub with per-player telemetry feeding a difficulty ranking. (writeup not done yet)
  • rygamb: a slot machine with carefully tuned near-miss psychology. (writeup not done yet)
  • lendfishing: a fishing minigame with a weighted loot table built from MSC classes. (writeup not done yet)
  • Ultimate ultimate tic-tac-toe: tic-tac-toe where each square is a game of ultimate tic-tac-toe, in the browser. (not done yet)
